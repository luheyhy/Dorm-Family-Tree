# 宿舍趣味辈分图 🎓

一款适合大学宿舍使用的趣味辈分管理工具，用搞笑的方式记录宿舍成员之间的"父子关系"！

## 功能特点

- 🎮 **拖拽交互**：拖动成员到另一个人的上半部分认爹，下半部分拜儿
- 🔗 **关系管理**：支持添加、删除成员，修改名称，断开父子关系
- 🔀 **随机排辈**：一键随机生成新的辈分关系
- 📸 **图片导出**：导出PNG图片分享
- 📄 **PDF导出**：导出PDF文档保存
- 💾 **数据持久化**：自动保存到浏览器LocalStorage
- 📂 **导入导出**：支持导出/导入JSON数据备份

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件即可使用
2. **添加成员**：点击"➕ 添加成员"按钮
3. **建立关系**：拖拽一个成员到另一个成员身上
   - 拖到上半部分 → 认对方做"爹"
   - 拖到下半部分 → 拜对方做"儿子"
4. **修改名称**：点击成员卡片上的 ✏️ 按钮
5. **断开关系**：点击 🔗 按钮（只有有父亲的人才显示）
6. **删除成员**：点击 🗑️ 按钮

## 默认数据

程序预设了四个宿舍成员：
- 小泽（小浩的爹）
- 小浩（小王的爹）  
- 小王（小李的爹）
- 小李（最年轻辈分）

## 技术栈

- 纯HTML + CSS + JavaScript
- TailwindCSS（CDN）
- html2canvas（图片导出）
- jsPDF（PDF导出）

## 注意事项

- 数据保存在浏览器LocalStorage中，清除浏览器数据会丢失
- 建议定期导出JSON备份重要数据
- 父子关系不能形成循环（会出现"共轭父子"提示 😄）

## 直接使用

无需安装任何依赖，下载后双击 `index.html` 即可在浏览器中运行！
